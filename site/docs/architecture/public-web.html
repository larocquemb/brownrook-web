Public Web Architecture

Brown Rook's public site is separated from the private infrastructure it describes. The landing page remains available even when the lab or its live services are offline.

Always-on public site

  1. DNS
  2. Global HTTPS content delivery
  3. Private object storage origin

HTTPS is enforced at the edge. The storage origin is not publicly accessible and serves content only through the content-delivery layer.

Live telemetry demo

The live receipt-processing telemetry dashboard is a passwordless, read-only demonstration hosted by the lab. It updates every 60 seconds and may be unavailable during lab maintenance even when this public site remains online.

Only aggregate operational measurements are published. The dashboard excludes logs, traces, host and queue identities, receipt identifiers, and financial data. Full monitoring access remains authenticated.

GitOps status

Argo CD is reachable through the public site ingress for authenticated deployment status and administration. It does not permit anonymous access.
